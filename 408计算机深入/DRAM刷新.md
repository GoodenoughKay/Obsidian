# 🧠 先搞懂底层逻辑

DRAM 用电容存 0/1,电容会漏电,所以**每隔一段时间(通常 2 ms)必须把每一行重新充一次电**,这就是"刷新"。

三个关键事实必须刻在脑子里:

一,**刷新以"行"为单位**,不是以"单元"为单位。一次刷新 = 刷一行,而不是一个存储单元。

二,**刷新周期 = 2 ms**(这是一个几乎所有题目默认的标准值,除非题目另给)。意思是在 2 ms 内,**所有行都必须被刷新一次**。

三,**一次刷新操作占用一个存储周期**。存储周期比如是 0.5 μs,那刷新一行就占用 0.5 μs,期间 CPU 不能访存。

---

# 📊 三种刷新方式深度对比

假设一个 DRAM 芯片**有 128 行**,存储周期 $T = 0.5,\mu s$,刷新周期 $2,ms = 2000,\mu s$。用这个具体例子把三种方式讲透。

## ① 集中刷新

**策略**:平时 CPU 正常访存,到某个时间点**一口气把 128 行全刷完**,然后再回到正常访存。

**时间轴**:

```
|←——— 2000 μs 总周期 ———→|
[可访存 1936 μs][集中刷新 64 μs]
                ↑
               死区!CPU 完全不能访存
```

计算:

$$\text{死区时间} = 128 \text{ 行} \times 0.5,\mu s = 64,\mu s$$

$$\text{可访存时间} = 2000 - 64 = 1936,\mu s$$

**特点**:

- 优点:CPU 访存时几乎不受干扰(大部分时间自由访问)
- 缺点:**有死区**(64 μs 内 CPU 啥都干不了,这对实时系统是灾难)

## ② 分散刷新

**策略**:把"存储周期"人为拉长,每次访存后**紧接着刷新一行**。也就是系统的存储周期从 $T$ 变成了 $2T$。

**时间轴**:

```
[访存 0.5μs][刷新 0.5μs][访存 0.5μs][刷新 0.5μs]...
 ←——— 一个系统周期 1 μs ———→
```

**特点**:

- 优点:**无死区**(刷新均匀穿插在访存之间)
- 缺点:**存储周期变成 2T**,整体访存速度减半!

⚠️ 关键理解:分散刷新的刷新周期**不是 2 ms**。每访存一次就刷一行,128 次访存就把所有行刷完了,刷新周期 = $128 \times 1,\mu s = 128,\mu s$,远小于 2 ms(刷得过于频繁,浪费)。

## ③ 异步刷新(实际系统采用)

**策略**:前两种的折中。**把 2 ms 均匀分给 128 行**,每隔一段时间刷一行。

**时间轴**:

```
刷新间隔 = 2000 / 128 ≈ 15.6 μs
[访存 15.6μs][刷新 0.5μs][访存 15.6μs][刷新 0.5μs]...
                ↑
          死区只有 0.5 μs
```

计算:

$$\text{刷新间隔} = \frac{2000,\mu s}{128 \text{ 行}} \approx 15.6,\mu s$$

**特点**:

- 死区很短(每次只有一个存储周期 0.5 μs)
- 整体访存速度接近原始速度
- **实际 DRAM 采用的就是这种方式**

# 🎯 典型题型大盘点

## 题型一:死区时间计算(集中刷新)

**例题**:DRAM 容量为 $1K \times 1$ 位,刷新按行进行,存储周期 0.5 μs,刷新周期 2 ms。若采用集中刷新,死区占刷新周期的百分比是多少?

**破题思路**:

- $1K = 1024 = 32 \times 32$ 位矩阵,**行数 = 32 行**(开平方!后面详细说)
- 死区 = $32 \times 0.5 = 16,\mu s$
- 占比 = $16 / 2000 = 0.8%$

## 题型二:刷新间隔计算(异步刷新)

**例题**:某 DRAM 有 256 行,刷新周期 2 ms,采用异步刷新,问刷新间隔是多少?

**答案**:$2000 / 256 \approx 7.8,\mu s$,即每 7.8 μs 刷一行。

## 题型三:刷新方式对比选择题(最常考)

典型选项陷阱:

|说法|对错|
|---|---|
|分散刷新没有死区|✅|
|集中刷新效率最低|❌(集中刷新访存速度最快,只是有死区)|
|异步刷新是前两种的折中|✅|
|刷新和存储器的读操作类似|✅(都是按行读出再写回)|
|刷新需要 CPU 控制|❌(**由存储器自己的刷新控制电路完成**)|

# 🚨 最容易踩的坑:行数怎么算?

这是区分学霸和普通学生的关键点!

**核心公式**:芯片存储单元按**二维矩阵**排布,为了让行地址和列地址的位数尽量均衡(这样译码器最经济),厂家会尽量把矩阵做成**接近正方形**。

$$\text{行数} \approx \sqrt{\text{芯片容量}}$$

常见值必须背下来:

|芯片容量|行 × 列|行数|
|---|---|---|
|$1K \times 1$|$32 \times 32$|**32**|
|$4K \times 1$|$64 \times 64$|**64**|
|$16K \times 1$|$128 \times 128$|**128**|
|$64K \times 1$|$256 \times 256$|**256**|
|$256K \times 1$|$512 \times 512$|**512**|
|$1M \times 1$|$1024 \times 1024$|**1024**|

**⚠️ 超级大坑**:有些题目直接告诉你"行数 = 128"或者"矩阵为 $256 \times 256$",这时候直接用题目给的数字,**不要自己开平方**。

另一个坑:有时候芯片是 $2K \times 8$ 这种非平方数,题目通常会直接说明行数,或者给出"行数 = 列数"的假设。

# 📝 一个完整例题(真题风格)

**题目**:某 DRAM 芯片容量 $16K \times 1$ 位,存储周期 500 ns,刷新周期 2 ms。分别计算:

1. 采用集中刷新的死区时间
2. 采用分散刷新的系统存储周期
3. 采用异步刷新的刷新间隔

**解答**:

$16K = 16384$,按 $128 \times 128$ 组织,**行数 = 128**。

**① 集中刷新死区**:

$$t_{死区} = 128 \times 500,ns = 64000,ns = 64,\mu s$$

**② 分散刷新系统周期**:

$$T_{系统} = 2 \times 500,ns = 1000,ns = 1,\mu s$$

(访存速度减半)

**③ 异步刷新间隔**:

$$t_{间隔} = \frac{2,ms}{128} = \frac{2000000,ns}{128} \approx 15625,ns \approx 15.6,\mu s$$

# 🎪 高频考点总结

**选择题高频点**:

- 刷新**按行**进行,不按单元
- 刷新由**存储器内部电路**完成,不需要 CPU 参与
- 刷新对 **CPU 透明**(CPU 不知道在刷新)
- 刷新时不输出数据到数据总线(和读操作的区别)
- SRAM **不需要**刷新,只有 DRAM 需要

**计算题高频点**:

- 集中刷新的死区时间 = 行数 × 存储周期
- 异步刷新间隔 = 刷新周期 / 行数
- 分散刷新下系统周期变成原来的 2 倍
